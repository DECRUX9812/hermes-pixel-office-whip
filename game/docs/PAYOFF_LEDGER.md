# PAYOFF LEDGER — HERMES: THE LAST OPEN DOOR

**Status:** Canon; live document, reconciled with STORY_BIBLE §10
**Companion docs:** STORY_BIBLE.md (§10 is the canonical foreshadow index — this
ledger is the complete closure map of objects, lines, mechanics, relationships,
identities, and symmetries), CHAPTER_BEATS.md (§11 continuity checklist is the
gate), WORLD_BIBLE.md

**The rule:** no setup without a payoff; no payoff without a setup. Deleting
either half is a revision event (see NARRATIVE_RISKS W-02). Every row below has a
disposition:

- **PAID** — closed on screen / in a playable scene.
- **CARRIED** — planted, returned to later, then closed.
- **REMEMBERED** — deliberately *not* returned; the refusal to resurrect is itself
  the payoff, and it is canon.
- **STRUCTURAL** — a mechanism, not a moment; verified by the build, not by a line.
